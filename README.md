### 🥋 Projeto em destaque: TatameFlow

Sistema de gestão para academias de Jiu-Jítsu, pensado a partir de uma necessidade real do meu próprio professor: controlar presença e progressão de grau/faixa sem depender de planilha ou papel. A ideia central é usar reconhecimento facial sobre a foto de grupo que a turma já tira ao final de cada treino — sem exigir nenhum cadastro extra do aluno.

**Stack:** Java · Spring Boot · PostgreSQL · AWS Rekognition
